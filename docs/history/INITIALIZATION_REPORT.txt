🚀 PROSSIMI PASSI PER INIZIARE

1. CONFIGURA API KEY OPENAI
   ────────────────────────────────────────────────────────────────────
   
   Opzione A - Setup Automatico (Raccomandato):
   
   PS> python setup.py
   
   Opzione B - Manuale:
   
   PS> copy .env.example .env
   Poi modifica .env con la tua chiave OpenAI
   

2. IMPORTANTE: RIMUOVI CHIAVI HARDCODED
   ────────────────────────────────────────────────────────────────────
   
   Nei file: archive_manager.py, analizer2.py, LiA.py
   
   PRIMA:
   openai.api_key = ("sk-proj-DGIPN88y6aFwNuQqh83_kUqCGFG...")
   
   DOPO:
   import os
   from dotenv import load_dotenv
   load_dotenv()
   openai.api_key = os.getenv('OPENAI_API_KEY')
   
   Installa python-dotenv:
   PS> pip install python-dotenv


3. AVVIA IL SISTEMA
   ────────────────────────────────────────────────────────────────────
   
   PS> python start.py
   
   Oppure direttamente:
   
   PS> python main.py
   > Inserisci la data (YYYY-MM-DD): 2022-02-24


4. TESTA CON DATE STORICHE IMPORTANTI
   ────────────────────────────────────────────────────────────────────
   
   • 2001-09-11  → Attacchi Twin Towers
   • 2008-09-15  → Fallimento Lehman Brothers
   • 2020-03-16  → Crollo COVID-19
   • 2022-02-24  → Invasione russa Ucraina
