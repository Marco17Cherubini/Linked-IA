🚀 AVVIO RAPIDO (3 METODI)

METODO 1 - Script Automatico (Windows):
  
  1. Double-click su: start-web.bat
  2. Scegli React (1) o Vue (2)
  3. Aspetta che si aprano i terminali
  4. Apri browser su localhost:3000 (React) o :3001 (Vue)


METODO 2 - Manuale (React):

  Terminal 1 - Backend:
  PS> python api_server.py
  
  Terminal 2 - Frontend React:
  PS> cd frontend-react
  PS> npm install    # Solo prima volta
  PS> npm run dev
  
  Browser: http://localhost:3000


METODO 3 - Manuale (Vue):

  Terminal 1 - Backend:
  PS> python api_server.py
  
  Terminal 2 - Frontend Vue:
  PS> cd frontend-vue
  PS> npm install    # Solo prima volta
  PS> npm run dev
  
  Browser: http://localhost:3001

         ↓

🐛 TROUBLESHOOTING COMUNI

1. "Cannot find module"
   → cd frontend-react (o frontend-vue)
   → rm -r node_modules
   → npm install

2. "Port already in use"
   → Cambia porta in vite.config.js
   → server: { port: 3002 }

3. "CORS Error"
   → pip install flask-cors
   → Riavvia api_server.py

4. "API not responding"
   → Verifica backend running (Terminal 1)
   → curl http://localhost:5000/api/health

5. Node.js non installato
   → Download: https://nodejs.org/
   → Versione richiesta: 16+
